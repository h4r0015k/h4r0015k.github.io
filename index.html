Hey, I'm Nikhil Sahani.

I'm a Senior Product Engineer with 7+ years of experience, mostly building backend systems. I like working on features from start to finish, but I care a lot about the backend side: keeping things fast, handling scale, and making sure services don't break.

A selection of production tools and systems experiments. Some built to solve user problems; others built to dissect protocols, memory layout, and runtime mechanics from scratch.

Mountain
[ LIVE APP ↗ ] [ SOURCE ↗ ]

Local-first, zero-knowledge browser password vault. Explores air-gapped secret isolation using the Web Crypto API, AES-256-GCM authenticated encryption, and deterministic 12-word BIP-39 recovery phrases. Persisted in client-side IndexedDB with zero tracking and zero server dependencies.

AES-256-GCM WEB CRYPTO API BIP-39 INDEXEDDB LOCAL-FIRST
Memory
[ SOURCE ↗ ]

Custom heap memory allocator implemented in pure ANSI C providing malloc, free, realloc, and calloc. Built to understand memory alignment, heap fragmentation, and chunk headers from scratch; verified against real Linux binaries via dynamic linker interposition (LD_PRELOAD).

ANSI C VIRTUAL MEMORY LD_PRELOAD POSIX SYSTEM INTERNALS
IRCBot-C
[ SOURCE ↗ ]

Minimal RFC 1459 IRC client written from scratch in ANSI C over raw POSIX/BSD sockets. Handles direct TCP streams, packet framing, non-blocking I/O polling, and keep-alive ping/pong loops strictly at the system call boundary without third-party network libraries.

ANSI C BSD SOCKETS RFC 1459 TCP STREAMS
WhatBot
[ SOURCE ↗ ]

Early automated WhatsApp cryptocurrency micro-tipping bot (2015). Built on reverse-engineered WhatsApp protocol layers via Yowsup, multi-signature transaction APIs, and stateful ledger tracking in MySQL to explore conversational payments before official APIs existed.
