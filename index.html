// ABOUT

Hey, I'm Nikhil.

I started playing around with code and computers long before I ever worked professionally. What hooked me back then is the same thing that keeps me excited today: genuine curiosity about how software works under the hood, experimenting with new languages and runtimes, and building things from scratch just to see how they tick.

Over the past 7+ years, that curiosity grew into building production backend services, distributed systems, and applied AI workflows. Most of my day-to-day work has centered on concurrency and scale: edge caching for high-traffic media sites, transaction safety in fintech systems, and designing services that stay fast and reliable under pressure.

Lately, I spend a lot of time working with applied AI: integrating LLMs into backend pipelines, building pragmatic agentic tooling, and designing structured workflows that solve real problems reliably without the hype.

Whether it's cloud infrastructure or emerging tech, I have a strong bias for simple, predictable architectures that run quietly and don't wake anyone up at night.

Custom heap memory allocator implemented in pure ANSI C providing malloc, free, realloc, and calloc. Built to understand memory alignment, heap fragmentation, and chunk headers from scratch; verified against real Linux binaries via dynamic linker interposition (LD_PRELOAD).

Minimal RFC 1459 IRC client written from scratch in ANSI C over raw POSIX/BSD sockets. Handles direct TCP streams, packet framing, non-blocking I/O polling, and keep-alive ping/pong loops strictly at the system call boundary without third-party network libraries.

ANSI C BSD SOCKETS RFC 1459 TCP STREAMS
